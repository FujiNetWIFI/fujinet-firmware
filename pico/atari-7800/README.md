# pico/atari-7800

FujiNet for the Atari 7800: an RP2354B cartridge with 512K of SRAM that boots past the console's
signature check, loads any image the ESP32-S3 pushes into the SRAM, runs it there, and serves a
memory-mapped mailbox, a POKEY and a High Score Cart.

## How it fits
- The console addresses the SRAM itself: A0-A12 and D0-D7 go straight to it. A PIO slot table
  indexed by A13-A15 supplies the page and whether the SRAM may answer or be written, and 74HCT
  gates decide who drives D, so no software sits in a game's data path; MARIA reads the cart too.
- Power-on: the cart serves a signed 4K block at `$F000`. The BIOS checks it and starts it; its
  reset vector jumps to the loader, which copies CONFIG into the SRAM.
- A push lands in `fuji_store` inside MOUNT_IMAGE, as on every sibling. The client jumps to the
  loader, which copies the image in 1K slices from the reply window. The cart then hands a game to
  the console's own BIOS, mapped back in, when this console's BIOS would start it and nothing has
  locked INPTCTRL; otherwise the loader starts it with the BIOS's exit state.
- GAME: a pushed image runs from the SRAM, the mailbox off. APP: an image that carries the claim
  keeps the loader and arena below `$1000` and, if its claim sets the RAM flag, 16K of cart RAM at
  `$4000`.
- The ESP32 side is the `fujiversal-atari7800` board ([lib/bus/rs232/](../../lib/bus/rs232/) over
  USB CDC).

## Build
- `./build.sh` signs the boot block and builds the loader and the clients into `build/` (cc65:
  ca65 and ld65). `./build-cart.sh` bakes a client (`build/config.bin` from fujinet-config
  `atari7800/` if present), the loader and the boot block into `build/gen` and builds the
  firmware; `--baked` builds from `firmware/baked/` alone, `--bake` refreshes it.
- `make -C firmware/host_test` runs the host tests.
- `emu/apply.sh <mame>` grafts the device (`-cartslot fujinet`); a single-driver build is enough:
  `make SUBTARGET=a7800 SOURCES=src/mame/atari/a7800.cpp`, with `REGENIE=1` the first time
  (`apply.sh` edits `scripts/src/bus.lua`). `./run.sh` runs a client; `IMAGE=` puts any image in
  the SRAM from power-on; `HSC=` installs the High Score Cart.

## Notes
- Edge (32 pins): A0-A15, D0-D7, R/W, PHI2, HALT, /IRQ, audio in. No chip select, no reset line;
  a power cycle sends the cart back to the boot block.
- Software for this cart never writes `$00-$1F`: until locked, every TIA write replaces INPTCTRL,
  and an unlocked INPTCTRL is what lets a game go back through the BIOS. Sound comes from the
  cart's POKEY at `$0450`.
- Mappers: MAME's `a78_rom`, `pokey`, `sg`, `sg_pokey`, `sg_ram`, `sg9`, `mram`, `abs`, `act` and
  `hsc`, each matching MAME's device byte for byte, with No-Intro's Activision layout. The 8K
  SuperGame RAM boards mirror their RAM as their 6264 does, where MAME indexes past an 8K buffer.
- The mailbox's `$0600-$0FFF` is free space by the 7800 Software Guide, and no shipped device used
  it.
- POKEY reads in MAME come from MAME's own POKEY; the firmware's synthesiser is checked against
  MAME's recordings of `pokeytest`, Ballblazer and Commando (`pokeycmp.py --game`). MAME's
  output stage is a resistor network, the firmware's a linear sum.
- The firmware image includes `firmware/src/pokey.c`, transcribed from MAME's `pokey.cpp`
  (BSD-3-Clause, copyright Brad Oliver, Eric Smith, Juergen Buchmueller); the full notice and
  conditions are in that file's header.
- High scores are AppKeys under creator `0x7800` (`HSC_CREATOR` in `firmware/include/hsc.h`,
  registered on the wiki); the HSC ROM is the user's own file, installed from CONFIG, never baked.
- `tools/7800sign/7800sign.c` is Bruce Tomlin's signer (version 1.0 of 2004-06-20) from
  [7800basic](https://github.com/7800-devtools/7800basic), LGPL-2.1 (`tools/7800sign/COPYING.LGPL`),
  unmodified. `tools/mkbootblk.py` builds it into `build/` to sign and verify the boot block; it
  is never linked into the firmware.
- The board is a Rev0 schematic (fujinet-hardware `ATARI-7800/FujiNet-7800-Rev0`), not yet
  built; everything here ran in host tests and MAME only.
