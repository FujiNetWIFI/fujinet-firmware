# Implementation Plan: A8CAS FSK Chunk Playback

## Overview

This task list implements the **approved revised Requirements and Technical Design** for generic A8CAS raw `fsk ` chunk playback in the Atari FujiNet cassette subsystem.

The previous implementation associated with closed PR #1590 is **reference code only**. Its completed checkboxes are not inherited here because the approved design has materially changed the payload-memory strategy, RMT transaction payload, ISR-visible allocation rules, test surface, and hardware acceptance corpus.

Implementation must remain generic and standards-based:

- Runtime detection of raw FSK is based only on the 4-byte Chunk_Type `"fsk "` (`0x66 0x73 0x6B 0x20`).
- Do not add filename-, game-, country-, Turbo-Software-, magic-value-, or source-signature-specific runtime behavior.
- `Night Knight.cas` is **not** part of the Real_World_Acceptance_Corpus and must not be used as evidence of Turbo Software compatibility unless independently proven to correspond to the referenced implementation.
- The local/manual Real_World_Acceptance_Corpus comprises at minimum:
  - `tt_international.cas`
  - `tt_river_raid.cas`
  - `turbo_software_missile_command.cas`
- The corpus must not be committed, redistributed, or used as CI fixtures.
- Source correlation against `https://github.com/a8dogdark/atari_turbo_software` is validation evidence only and must never become runtime detection logic.
- Do not reopen PR #1590. A future contribution, if validation succeeds, must be a **new PR** based on the revised SDD and evidence.

Tasks should be completed in order. Every implementation task below starts unchecked until the revised design has been implemented and re-verified.

## Completion Criteria

The revised implementation is ready for a **new** Pull Request only when all of the following are true:

- Requirements and Technical Design remain approved and this revised task plan has been completed.
- The normal FUJI path recognizes `fsk ` only from its exact 4-byte Chunk_Type and supports both interleaved and pure raw-FSK A8CAS images.
- Each FSK duration is decoded as little-endian `uint16`, interpreted in 0.1 ms units, and assigned a level strictly from original value-index parity.
- Zero-duration values preserve subsequent parity and emit no artificial duration.
- Large valid chunks across the A8CAS `uint16` length range are not rejected by an arbitrary implementation size cap.
