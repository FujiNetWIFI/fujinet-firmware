# data

Source for the device's flash filesystem image: the web UI, printer fonts, boot disks and the
configuration template `webui/template/fnconfig.tmpl.ini`.

## Layout
| Path | Defines |
|---|---|
| `webui/` | The only source directory. Its own [README](webui/README.md) describes the common, template and device-specific trees and the per-board yaml configs |
| `BUILD_*/` | Generated by `build_webui.py` on every build, deleted and recreated each run, git-ignored |

## How it fits
- `platformio-ini-files/platformio.common.ini` sets `data_dir` to the `BUILD_*` directory of
  the active platform, so that directory is what the PlatformIO filesystem target packs into the
  LittleFS image.
- The PC build writes the same output into its build directory, and the `dist` target copies it
  next to the executable.
- At runtime the web server serves the image's `www` directory through `fsFlash`, and the printer
  emulators read their fonts from the image's font directory.

## Build
`build_webui.py` runs as a PlatformIO pre-script on ESP32 and as the `build_webui` CMake target on
PC. After a change under `webui/`, `./build.sh -f` (upload filesystem) is required; `-u` alone does
not refresh the image.

## Notes
Nothing else belongs here. Every file under `webui/common/`, `webui/template/` and the matching
`webui/device_specific/` platform tree ships verbatim in the image.
